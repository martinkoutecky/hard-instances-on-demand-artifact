# Python dependencies for the ALENEX 2027 artifact "Hard Instances on Demand".

# Versions below are the ones used for every measurement reported in the paper
# (AMD Ryzen 5 8600G, Python 3.12, Linux x86-64).  Pinning is deliberate: the
# SAT branch labels in the paper depend on which backends python-sat exposes.
#
#   python3 -m venv .venv && . .venv/bin/activate
#   pip install -r requirements.txt
#
# Not in this file, and needed only for the subsets noted:
#   * pyconcorde          -- TSP and Hamiltonian-cycle suites (the code imports
#                            concorde._concorde; a `concorde` executable is not
#                            used).  Measured with pyconcorde 0.1.0 at
#                                pip install "pyconcorde @ git+https://github.com/jvkersch/pyconcorde.git@a573c1b73244f0dc7cf88ddd18ccfa4c65919974"
#                            Its build compiles Concorde from source; on recent
#                            toolchains Concorde's configure may need an explicit
#                            --host (see the pyconcorde README for building
#                            against a separately built Concorde).
#   * IBM CP Optimizer    -- the CP Optimizer arm of the flow-shop (NPFS) suite.
#                            Free option, no IBM account needed:
#                                pip install cplex==22.1.2.1
#                            installs the Community Edition `cpoptimizer` onto
#                            PATH, byte-identical to a binary we measured with.
#                            It is kept out of this file because installing it
#                            accepts IBM's license terms.  See the README
#                            section "IBM CP Optimizer" for details.
